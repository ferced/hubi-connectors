# HUBI para Claude

La skill, los manifests y el contrato exportado del paquete se distribuyen bajo MIT (copyright 2026 Ferced Labs). Consultá `LICENSE` y `LICENSE-SCOPE.md` para el texto y su alcance; esta concesión no incluye iconos, marcas, servicio, hub ni firmware.

Vinculá el conector HUBI y pedí leer tus pantallas o preparar una propuesta. La skill hubi usa capacidades actuales, revisa la simulación y conserva ask/auto. Las claves de proveedores se completan sólo en Conexiones del hub.

La vinculación, consentimiento y revocación remotos viven en /connectors. El control de dispositivos requiere un pedido explícito, hubi.control y permiso local adicional. Una simulación no acredita recepción del dispositivo.

El conector alojado usa el cliente OAuth confidencial predefinido introducido en el portal de Anthropic, fuera del paquete. El plugin no contiene credenciales. Claude Code requiere configuración de cliente propia o el conector ya vinculado de claude.ai; la identidad alojada no se reutiliza automáticamente en Code. Consultá la documentación pública del editor incluida en los metadatos.
